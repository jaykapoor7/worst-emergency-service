## Remaining live verification

The cloud browser policy rejected navigation to the local HTTP preview. Browser-level layout, physical touch behavior, actual audio playback, and a browser uninterrupted 20-call run have not been verified. They must be exercised against the deployed HTTPS site before claiming full browser acceptance. Automated engine tests do not establish those results.

The Vercel connector initially rejected bare project creation with HTTP 403. Deployment and domain status must be confirmed from their final tool responses; this source package does not itself imply a live deployment.

## Intended acceptance pass on HTTPS

1. Select each opening branch in a fresh game and exercise its operation.
2. Confirm the caller follows that branch; visually inspect the lasting consequence.
3. Use pointer and keyboard controls. Exercise a deliberate poor response and verify advancement.
4. Refresh during a challenge, after a report, and during a promotion. Confirm safe replay or restoration.
5. Test mute and New Game (including cancelling New Game).
6. Play at least 20 uninterrupted calls in a browser, then continue through President and its next call.
7. At 1440, 390 and 320 CSS pixels, inspect overflow, readable calls, touch controls, and the live town.
8. Check browser errors, audio after a gesture, tab visibility pause, and reduced motion.
